# TransformPath 작업 현황과 남은 과제

사용법은 [README.md](../README.md)에 있다. 이 문서는 지금 상태와 다음에 할 일만 다룬다.

## 현재 상태

| 항목 | 상태 |
| --- | --- |
| 테스트 | macOS·Metal(Apple M4 Pro)에서 EditMode 293개 통과, 그래픽 Editor가 필요한 UI 9개는 배치 실행에서 건너뛰고 Editor에서 통과, PlayMode 27개 통과 |
| 실행 방법 | 저장소 루트의 `Tools/run-tests.sh` |
| Player | 실행을 확인하지 않았다 |

## 2026-10-31 결함 수정

회귀 테스트는 `TransformPathDefectRegressionTests`에 있다.

| 문제 | 수정 |
| --- | --- |
| 길이 약 3.16 미만의 경로나 구간에서 진행 방향으로 회전하지 않음 | 진행 방향을 거리 기준(최소 0.01)으로 계산한다. 경로 끝에서는 직전 회전을 유지한다 |
| 보간 중 이동 방식이 다른 구간으로 넘어가면 예외로 재생이 끝남 | 이동 방식이 바뀌면 보간을 취소한다. Seek로 옮겨도 같다 |
| 재개, 간격 증가, 경로 단축으로 간격이 부족해지면 `ConstraintViolation`으로 재생이 끝남 | 시작할 때 지정한 진행 상한만 위반으로 판정한다. 간격이 부족하면 대기한다 |
| 내부 Follower 리스너가 예외를 던지면 Manager 등록이 남아 뒤따르는 Agent가 영구히 막힘 | 내부 이벤트로 Queue가 등록을 해제한다. Manager도 재생이 끝난 등록을 앞 Agent로 계산하지 않는다 |
| 리스너 예외로 재생이 끝나도 `Animator.speed`가 0으로 남음 | 정리할 때 1로 복구한다 |
| 자유 재생을 일시정지 후 재개하면 `IsBlocked`와 속도 배율 0이 남음 | 대기열 밖 재생이 재개되거나 끝나면 표시 상태를 초기화한다 |
| TimeScale 0 이벤트의 지연 이벤트가 영원히 실행되지 않음 | 이 조합을 검증에서 거부한다 |

## 남은 과제

| 항목 | 현황 | 방향 |
| --- | --- | --- |
| Loop 경로의 간격 | 코드 판독. Agent 간 거리를 진행도 차이로 계산하므로 경로 끝과 시작을 잇는 간격은 보지 않는다 | Loop Queue가 필요해지면 순환 거리로 계산 |
| 리스너 예외로 끝난 재생의 공개 알림 | 재실패를 막기 위해 `StateChanged`를 보내지 않으므로, 내부 Follower 리스너는 `State`를 직접 확인해야 한다 | 현재 계약 유지 |
